## 原始产品需求与细项

以下保留最初制定的功能边界、场景及发布要求；历史安装/测试描述需结合上面的当前状态理解。


## 1. 产品目标与边界

让用户在使用 Weasel 输入时，自愿开启对**当前输入及可获得的邻近文本**的纠错检查，看到有根据、可忽略、可反馈的建议。首版针对错别字、漏字、重复字及明显的搭配错误；不承诺理解任意应用的完整文档，也不自动改写文字。

### 首版原则

- 正常输入优先：模型、网络或纠错界面故障不得阻塞按键、上屏、候选选择和原有设置。
- 建议属于辅助信息，不把模型建议直接插入 Rime 候选首位，也不以“错误”口吻断言不确定的判断。
- 默认关闭纠错；用户明确选择本地或联网模式后才开始分析。联网模式须先说明会发送哪些文本、发送给谁。
- 只处理实际可取得且已获允许的文本；取不到宿主上下文时降级为“仅检查本次输入”，不得暗示已检查整段上文。
- 首版不采集其他输入法的文字、剪贴板或全局键盘记录。不得把 Rime 用户词典当作全文历史。
- 本地学习以可删除的词表、反馈和配置为主；不在用户输入过程中自动更新模型权重。

### 需要优先回答的产品问题

- [ ] 确定目标用户及优先场景：聊天、邮件、长文写作、专业术语输入，分别需要哪些错误类型？
- [ ] 明确“接受建议”的含义：能安全定位原文时替换；无法定位或宿主拒绝编辑时提供复制建议，不假装替换成功。
- [x] 提供手动“检查文本”入口：管理纠错窗口中主动提交文字；不假定能读取任意当前选区。
- [ ] 决定用户词典、纠错记忆和模型运行状态是否跨设备同步；建议默认不上传纠错记忆。

## 3. 易遗漏的场景与预期处理

| 场景 | 预期处理 |
| --- | --- |
| 下一次输入发生在另一个应用、文档或输入框 | 不展示上一场景的待提示结果；按策略清除短期上下文。 |
| 模型返回时原文已编辑或光标已移动 | 丢弃结果或重新检查；不按旧位置替换。 |
| 宿主只暴露部分文本或拒绝只读编辑会话 | 降级为本次输入检查，并向用户准确表述检查范围。 |
| 用户故意输入生僻词、方言、品牌名或专业术语 | 保守提示；支持“这是正确的”和按应用的术语表。 |
| 用户调整本地提示阈值或更换模型 | 立即按新阈值处理后续建议；旧模型分数不跨模型复用；可恢复默认设置。 |
| 密码框、支付字段、疑似敏感内容 | 不分析、不存储、不发送；无法确认时禁用联网路径。 |
| 网络断开、服务启动慢、模型超时或崩溃 | 不阻塞输入；显示简洁状态，避免反复弹错；重试受限。 |
| 文本长于模型窗口 | 检查局部片段，按需分块；不静默截断目标错误及其邻近文字。 |
| 纠错提示与候选框、屏幕阅读器冲突 | 提示不抢焦点，位置可调，可通过键盘读取和关闭。 |
| 多个 Windows 账户或服务器用户 | 词表、反馈、缓存和日志按用户隔离。 |
| 用户关闭功能或删除学习数据 | 停止新请求、清除待处理结果，按说明删除对应本地记录。 |
