# 分发版验收与首启路径修复（2026-11-10）

## 当前结论

18a45c8 的安装文件、双架构注册、快捷方式和卸载入口检查通过，默认输入仍为搜狗。但首次启动发现阻断问题：安装器和新用户启动器将 `%APPDATA%\WeaseLC` 保存为 REG_SZ，现有 WeaselUserDataPath 对该类型直接按字面读取，Rime 因相对目录无法创建而部署失败，且上游部署返回值未报告该失败。旧包不可直接作为公开发布包。

日志证据：rime.weaselc 中 Error creating user data dir: %APPDATA%\WeaseLC，及 error creating directory ...\build。未出现配置向导，用户目录未建立。

## 修复范围

- 安装器在当前安装账户上下文展开默认资料目录，保存绝对路径；自定义路径保持原值。
- 启动器为新账户展开默认路径，并兼容迁移首包写入的精确默认占位字符串，不改其他自定义路径。
- 启动前拒绝相对目录并递归创建用户目录，目录错误直接报告失败。
- 设置页面将已保存的默认绝对路径识别为“默认位置”。
- 不修改 WeaselUserDataPath 和输入/纠错路径，避免影响已验证的普通输入和其他构建身份。
