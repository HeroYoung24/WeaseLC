# PowerShell 5.1 模型管理适配

2026-11-13

## 改动

- 模型管理接受 `pwsh.exe` 和 `powershell.exe`。有效的已保存路径优先，其次查找 PowerShell 7，最后从 Windows 系统目录获取 `WindowsPowerShell/v1.0/powershell.exe`。
- 启动脚本使用带 BOM 的 UTF-8，在 5.1 中显式加载自带的工具模块和 HTTP 程序集。旧模型目录继续提供权重和运行时，5.1 则从安装目录调用新版启动脚本，并将已有模型目录作为参数。
- 下载脚本使用 5.1 可用的绝对路径校验，在 5.1 中显式加载工具和压缩模块。保留专用目录、重解析点检查、断点文件处理和 SHA-256 校验。手动下载许可证使用基本解析，适用于非交互调用。
- 5.1 在编译标准输入关闭监听时会启动额外的编译进程，因此只为该启动任务增加 Job 内的进程配额。模型身份、端口、预热、后台运行和停止仍使用原有机制。脚本遵循当前执行策略。

本次调整面向安装后使用的模型管理。开发者构建和打包脚本仍以 PowerShell 7 为基线。
