# 纠错提示：鲁棒性与交互检查

更新：2026-10-16。本轮完成源码修复、双架构构建和独立宿主验证。**未安装或注册到日常输入法，真实应用兼容性尚未验收。**

## 本轮修复

- 记录每次成功输入后的预期光标位置和组合文字。鼠标移动插入点、拖选、外部粘贴、失焦或文本变化后，取消旧请求和建议；回到原位置不恢复旧建议。纯鼠标移动且编辑状态不变不会取消建议。
- 编辑通知、布局通知和定时只读校验共同检查状态。滚动、坐标不可读或被裁剪时隐藏；布局恢复且建议仍有效时重新显示。文档视图销毁时丢弃状态。布局事件依据 [ITfTextLayoutSink::OnLayoutChange](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itftextlayoutsink-onlayoutchange)。
- Tab 成功接受后，即使其他按键取消建议，也配对处理该次 Tab 的释放；修饰键不触发接受。回调期间保活服务对象，编辑请求退出时先解除重入标记再释放最后引用，避免宿主重入造成悬空访问。
- 慢请求遇到新提交或鼠标中断时终止旧子进程；损坏响应、子进程提前退出后可以继续处理下一次请求。
- 提示按实际文字、字号和 DPI 测量换行，分开显示原文、建议和按键说明；完整内容无法放下时隐藏，不截断纠错内容。优先避开候选框；测量和未变化的位置缓存以减少重复绘制。
- 提示保持不激活、鼠标穿透；使用 layered 与 transparent 样式实现跨线程穿透，依据 [Windows 窗口特性](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。系统颜色变化时重绘；高对比度实际验收仍待进行。
- 设置增加“离线预览”，只显示固定示例，不调用模型或写入宿主。布局修改即时预览，取消或关闭时销毁。数值必须是完整整数，拒绝 `320x`、将 `0.9` 当作 0 等输入；自定义分数关闭时，未启用的无效草稿不会阻止使用默认阈值。

## 场景与验证方法

| 场景 | 检查行为 | 验证方式 |
| --- | --- | --- |
| 拼音打到一半移动光标 | 原建议取消，后续正常输入仍可提交 | 自有 TSF 文档发出真实选择/编辑通知，经过生产文本编辑 sink |
| 拖选、粘贴、切换焦点 | 不替换过期范围；回到原位置不复活 | 自有文本存储改变选择/正文，模拟服务焦点事件 |
| 滚动、坐标裁剪、视图关闭 | 隐藏、可恢复或销毁 | 宿主布局状态与生产布局回调 |
| 请求慢、旧响应晚到、进程退出 | 回收旧任务，下一次任务可成功 | 固定语料子进程，真实匿名管道与 Job |
| 空格/中文可执行文件路径 | 正确启动检查进程 | 测试输出目录内的独立副本 |
| 只读、密码或未知输入类型 | 不继续读取或替换 | 输入范围/状态通知与读取计数 |
| Tab 查询、长按、修饰键及释放 | 查询只读；至多接受一次；普通键保持原语义 | 生产接受路径；仅测试线程保存/恢复键盘状态 |
| 编辑回调释放服务外部引用 | 完成编辑，安全析构和卸载 | 自有宿主在 GetSelection 回调释放全部外部服务/按键接口引用 |
| 长建议、小宽度、大字号与 DPI | 完整排版或隐藏，不覆盖候选 | 最大 32 单元建议、96/144/192/288 DPI 几何及绘制检查 |
| 参数非法、取消、预览退出 | 拒绝错误数值，不误保存，窗口销毁 | 简体/繁体/英文原生设置界面自检 |

自有宿主事件用于验证生产逻辑，不等同于真实鼠标操作验收。未注入全局鼠标或键盘事件；仅对自有合成文档使用 `TF_TMAE_NOACTIVATETIP`，不调用 TIP ActivateEx，不建立日常 WeaselServer 会话。未被纠错层接管的按键不在未激活测试服务上转发到日常 Rime。

## 最终结果

以下均为 x64 和 Win32 **每架构**的通过项数，失败为 0：

| 检查 | 数量 |
| --- | ---: |
| 模型客户端、设置与协议离线回归 | 117 |
| 原提交路径独立宿主回归 | 23 |
| 自动提示与中断/重入回归 | 103 |
| Qwen3-4B 真实本地 HTTP 自动链路 | 17 |
| 三语言原生设置与离线预览 | 189 |

普通 Release 的 TSF、传统 IME、Server、Deployer 双架构构建通过；保留既有编译警告。探测 DLL 构建通过，加载、类工厂、组合检查模式通过，测试窗口类注销及 DLL 实际卸载通过。

模型只接收固定合成文本。最后一次提交至建议就绪观测：x64 3343 ms、Win32 1063 ms，包含防抖、子进程启动及 HTTP；单次观测不能比较架构性能，也不代表模型质量验收。
