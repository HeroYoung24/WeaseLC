## 1. 已知结果与待验证问题

- 进程内 manifest + `LOCALPROCESS` 路径已验证中文“你好”、语言栏、菜单与合成文档边界；x64、Win32 都有运行记录。
- 临时键盘类别与隐藏配置注册成功，新子进程能读取类别及部分配置元数据，但仍不能取得匹配的当前键盘身份。最后一次隐藏配置的 `ActivateProfile(FORPROCESS)=E_FAIL`，没有新的服务激活。
- 系统 COM 注册、配置启用、类别能力、加载路径及 TSF 缓存可能影响完整安装。这些是待验证因素，未确定旧 v2 的唯一根因。
- Microsoft 的 [TSF 注册文档](https://learn.microsoft.com/en-us/windows/win32/tsf/text-service-registration)说明，常规文本服务需要 COM 注册、TSF 配置及类别注册；进程内 manifest 测试不足以代替完整安装验收。

## 4. 按顺序验收

| 阶段 | 操作及通过条件 | 失败后的处理 |
| --- | --- | --- |
| 注册与加载 | 全新测试宿主确实加载正确架构的 DLL；实际激活计数增加；配置类别和当前键盘服务身份匹配；初始化成功 | 保存返回值和仅含元数据的日志，撤销本轮注册 |
| 基本输入 | 选中测试输入法后能输入、候选、上屏“你好”，中英文切换正确；图标属于本服务 | 停止后续上下文测试，排查输入路径 |
| 菜单和设置 | “管理纠错”与一次性探测菜单存在；管理窗口可打开/关闭；关闭模式默认生效 | 保留独立菜单与窗口结果，修正后回归基本输入 |
| 上下文边界 | 普通合成文本有限读取；未知类型跳过；密码类型拒绝；切换文档取消旧探测 | 禁止扩大读取，保留状态/计数而不记录正文 |
| 共存与生命周期 | 反复切换输入法/焦点、停用再激活、未结束组合时关闭宿主；原版及其他输入法按钮不被移除 | 比较对象身份、注册返回值和引用计数，不绕过身份检查 |
| 撤销与恢复 | 无测试配置列表项、COM/TIP/category 残留；测试进程退出后 DLL 可卸载；原版仍能输入 | 若 DLL 被占用，只处理测试环境内已识别的测试宿主，恢复快照或基线 |

先完成一个架构与一个应用的全部阶段，再扩展第二架构、第二应用和多输入法共存。短期通过与长期稳定性分别记录；不能用一次成功覆盖此前间歇失败。测试框架的阶段编号只有在本次实际激活计数增加时才有效。
