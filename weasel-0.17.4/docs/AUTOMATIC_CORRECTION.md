# 自动提示、Tab 纠错与布局设置

更新：2026-10-16。代码已接入正式 TSF 构建；独立宿主通过双架构检查及本地模型联调。**尚未安装到日常系统，未通过真实应用兼容性验收。** 当前运行的原版 Weasel 0.17.0 不会因本次构建获得此功能。

## 已实现的行为

1. 在“管理纠错”选择本地 HTTP，设置接口与模型名。在“自动提示与布局…”中单独开启自动提示，最后在主窗口保存。默认关闭；旧版设置迁移后也保持关闭。
2. 仅捕获本输入法成功上屏的新文字。同一文档、同一插入位置、原文仍匹配的连续上屏片段可以合并，最多 1024 个 UTF-16 单元。超限时从当前片段重新积累；单次超限片段不送模型。不会自动读取已有整篇文档、剪贴板或其他应用内容。
3. 默认防抖 250 毫秒。每个 TSF 服务实例最多保留一个检查子进程，新提交取消旧进程。模型 HTTP 在 `WeaselDeployer.exe /correction-worker` 内执行，输入线程通过私有匿名管道传递有界数据，不等待推理。
4. 默认在下一次同一输入框开始拼音组合时，将建议放在候选框旁；也可选择检测完成后立即显示，此时没有候选框可跟随时以宿主光标矩形定位。坐标无效或应用自行接管候选 UI 时，组合期间不显示提示。
5. 提示可见且有效时，普通 Tab 接受当前第一条建议。重新检查原文、光标、文档、输入类型、生命周期和设置版本后，用同步 TSF 写锁修改目标范围；不发送模拟按键。保留当前拼音及其候选状态，替换长度改变后仍使用跟踪范围恢复光标和组合边界。
6. Esc 丢弃本次建议，并继续交给原输入法处理。没有有效建议、Tab 开关关闭、Shift/Ctrl/Alt/Win 修饰键或写锁被拒绝时，纠错层不接管 Tab。按住 Tab 不重复应用；`OnTestKeyDown` 查询不修改文字。
7. 模型返回多条建议时，当前只展示第一条；接受后清除旧建议和本次缓存。不会自动改字，也不会改动 Rime 高频词排序或把模型分数与词频混算。

详见本轮 [鲁棒性与交互检查](CORRECTION_ROBUSTNESS.md)：光标/选择/粘贴中断取消、布局重检、回调重入及离线预览已补齐。设置数值要求完整整数；最低模型分数在界面使用 0–100 的整数百分数。

## 参数

| 参数 | 默认 | 范围/说明 |
| --- | --- | --- |
| 自动提示 | 关闭 | 仅本地模型；联网自动读取尚未开放 |
| Tab 接受 | 开启 | 关闭后仅显示建议；可使用管理窗口手动检查 |
| 提示时机 | 下一次输入 | 或模型结果到达后立即显示 |
| 位置 | 右侧 | 左侧、下方；优先避开候选框并限制在工作区内，完整内容无法放下时隐藏 |
| 间距 | 8 | 0–48，96 DPI 逻辑像素 |
| 宽度 | 320 | 180–640，96 DPI 逻辑像素 |
| 字号 | 14 | 10–24，96 DPI 逻辑像素 |
| 防抖 | 250 ms | 100–2000 ms |
| 最低模型分数 | 保守 0.90 | 复用现有敏感度/自定义阈值；不是校准后的正确率 |

设置使用版本 3 格式，继续保存到现有 `SettingsV2` 注册表值，兼容读取版本 2。密钥、联网确认及输入正文不保存。自动模式暂不支持需要访问密钥的本地服务。布局子窗口“确定”只更新主窗口内存，主窗口“保存”后才生效；取消不会保存。

布局设置提供固定文字的离线预览，不调用模型、不修改文档。提示按实际内容换行，不截断原文或建议；布局不可读时隐藏，恢复后在有效期内重新校验显示。

原文变化、文档/焦点切换、光标偏离预期位置（含在预编辑内移动）、拖选或外部粘贴、切换模式、保留词/设置改变或距本次提交 10 秒后，取消请求并隐藏建议。密码、私密、未知输入类型、只读文本、无法确认焦点或失去编辑锁时不替换。模型服务关闭、响应无效或超时时不会阻断中文输入。

## 管道与组合边界

`CorrectionAutomatic.h` 定义版本 1 固定长度协议：请求小于 4 KiB，返回最多 8 个候选；字符串、分数和偏移再次校验。管道只继承明确的标准输入/输出/NUL 句柄，不传递宿主指针、文件名、任意命令或密钥。子进程放入关闭即终止的 Job，取消和服务销毁只回收本服务创建的进程，无 Windows 服务注册。

最初连续输入测试发现：已有拼音组合时，在其范围外直接 `SetText` 会得到 `TF_E_RANGE_NOT_COVERED`；另外开启第二个组合也被拒绝。最终采用同一写锁内临时扩展原组合起点，纠错后恢复其跟踪起点，原拼音不提交、不重建。若宿主拒绝恢复，结束该组合且保留宿主文字，清除对应 Rime 组合，避免后续按键覆盖前文。这条拒绝恢复分支尚待真实宿主故障注入验收。

接口依据：[ITfRange::SetText](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itfrange-settext)、[ITfComposition::ShiftStart](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itfcomposition-shiftstart)。

## 验证与复现

使用匹配架构的 `WEASEL_CORRECTION_PROBE_BUILD=1` DLL 和 `test/CorrectionIntegration` 工程。诊断导出只存在于探测构建，正式 DLL 没有这些入口。

```powershell
# 在源码目录，先完成对应架构的探测 DLL、Deployer 和测试工程构建
./output/CorrectionIntegration/x64/CorrectionIntegration.exe ./output/Probe/v3/x64/weaselProbe.dll --automatic

# 先启动 local-model/Start-LocalModel.ps1 -Variant 4b；只使用内置合成样例
./output/CorrectionIntegration/x64/CorrectionIntegration.exe ./output/Probe/v3/x64/weaselProbe.dll --automatic-local E:/WeaseLC/weasel-0.17.4/output/WeaselDeployer.exe
```

`--automatic-local` 通过同一进程/管道代码调用 `/correction-worker-selftest`，这个诊断入口只接受固定的“这里有错子。”，只连接 127.0.0.1:18963，使用已部署的 `weasel-qwen3-4b`。不读取或修改用户设置/词表。它验证真实 HTTP 与写回，不代表开放语料质量合格。

两架构均不调用 TIP `ActivateEx`，只为自有合成文档使用 `TF_TMAE_NOACTIVATETIP`。不注册 COM/TIP、不切换系统输入法、不建立日常 WeaselServer 会话。

本轮结果：

- x64、Win32 普通 Release：TSF、传统 IME、Server、Deployer 构建通过；保留原有编译警告。
- 模型/设置离线检查：每架构 117 项。
- 三语言 GUI 检查：每架构 189 项，包括自动布局的范围、确定/取消和默认状态。
- 自动提示独立宿主：每架构 103 项，包括只读按键查询、一次接受、保留拼音、长度变化、连续提交上下文、过期原文、密码/未知字段、宿主拒绝写入、屏幕边界和 DLL 卸载。
- 真模型自动链路：每架构 17 项；本轮最后一次样例从提交至结果就绪约 x64 3343 ms、Win32 1063 ms，含防抖/进程启动/HTTP。单样例观测不构成性能基准。
