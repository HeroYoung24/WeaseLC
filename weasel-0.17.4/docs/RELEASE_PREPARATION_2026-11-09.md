# WeaseLC 发布准备

2026-11-09。当前本机独立测试安装仍为 98ef623。分发身份代码和安装包已独立实现，当前机器尚未安装分发版。

## 独立分发包

- 入口为 packaging/windows/Build-Distribution.ps1。专用 WEASELC_DISTRIBUTION_BUILD 分别编译 x64/Win32，输出到 output/Distribution。编译设置禁止与本机测试/探测构建混用。
- 分发版使用 Software\WeaseLC、独立管道/互斥体及新的 TSF CLSID、配置 GUID。原版和本机测试身份继续保留。
- NSIS 界面仅有许可证、安装位置、基础设置、进度和完成页。基础设置提供简繁体、当前安装账户的用户资料位置、登录启动；首次从开始菜单打开后调用原生输入方案和配色设置。
- 此首个分发版本要求卸载旧分发版后重装，保留用户资料。安装目标必须为空目录。卸载只处理确切的程序文件清单及独立注册，不删除资料和模型，不递归删除未知文件，不往 Windows 系统目录复制输入组件。
- 内置 x64 后端和 x64/32 位 TSF，目标为 x64 Windows 10+。ARM64、32 位操作系统及传统 IMM 组件不在本包中。安装界面暂为简体中文，程序设置仍有三种语言。
- 安装与当前安装账户的资料偏好在提权进程中保存。以另一管理员账户授权时，首次资料位置采用该安装账户的偏好，其他账户从自己的默认目录初始化。
- 默认选择登录启动，使用可取消勾选的启动快捷方式。完成页引导普通用户从开始菜单首次设置，避免在提权安装进程中部署用户字典。
- 版本暂定 0.1.0-beta.1 / 文件版本 0.1.0.1。当前包未签名，未公开发布。
- 包含 GPL、第三方声明及引擎/库/数据许可原文。准确对应源码发布包和最终再分发核对仍是公开发布门槛。
- Test-Package.ps1 只解包和逐文件校验、运行只读启动器及包内隐藏界面检查；不注册输入法。真实首次安装、取消/失败回退、卸载、重启释放和多账户仍须在测试环境验收。

## 已完成

- 非测试构建的输入法显示名为 WeaseLC，语言栏名称使用同一个入口。独立测试构建保留可识别的测试名称。
- 生产菜单隐藏上下文探测入口，管理纠错移除探测状态和未开放的 CLI 占位。测试构建的探测操作仍可用于排障。
- 简体、繁体、英文纠错界面统一调整分组边界、间距和按钮位置，连续提示设置集中到同一区域。保留最短展示、最长有效、数据记录和保存方式的必要说明。
- NSIS 查找支持 NSIS_ROOT、已安装的注册记录和 PATH，现有构建入口复用 find-nsis.bat。E:\NSIS 的 3.13 编译器已验证。
- x64/Win32 本机测试构建通过，界面自检各 363 项通过。预览图已核对主设置与自动提示窗口。

## 发布前仍需完成

1. 验证专用分发身份的首次安装、启动及卸载。常规上游构建身份仅保留给历史构建，不用于分发。
2. 分发统一使用 packaging/windows 的专用入口。原 output/install.nsi 和 WeaselSetup 保留为上游历史实现，不纳入分发包。
3. 安装失败、DLL占用、权限、回退和卸载演练，验证原有输入法及用户词库。新安装包须在干净环境验证。
4. 发布版本、更新通道、精确依赖锁定、对应源码包、版权许可材料、签名和校验值。
5. 连续提示的实际环境回归和模型质量、端到端延迟验收。当前仅有限定环境的通过记录。
