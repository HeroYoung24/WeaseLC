## 接入审查补改

原队列草稿依赖外部在写回期间暂停定时清理。生产模块增加显式BeginWrite/WritePending屏障：

- 必须先选中并验证当前项，才能开始事务；Accepted要求已经持有屏障，并由原写后独立确认结果调用。
- 事务期间暂停到期清理、队列推进、重新校验和新建议准入；来源变化返回失败，不能在此期间接受新的来源。
- 确认或明确作废后释放屏障，其他项继续隔离，必须推进来源版本并重新核对。

它是队列自身的保护，不替代现有TSF多阶段写回/焦点/代际检查。原WriteWordAndTail、拼音保留和不确定失败不重放逻辑未改动。
