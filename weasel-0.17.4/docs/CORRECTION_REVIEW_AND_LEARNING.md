# 纠错操作与用户习惯（2026-10-15）

## 2026-10-19 补充：复用学习能力，避免重复实现

用户在旧测试版反复输入“这里有错子”后，它成为常用候选。这与所带 Rime 的原生用户词典学习机制一致：提交事件由 `memory.cc` 管理，`script_translator.cc::Memorize` / `table_translator.cc::Memorize` 更新用户词典。本项目未新增一套自动高频短语缓存，也未改变这些底层学习算法。没有保留该旧测试词库的逐项证据，不能反推出这条短语的具体学习次数。

| 能力 | 负责模块 | 后续约束 |
| --- | --- | --- |
| 高频词、习惯短语及候选排序 | 原生 Rime 用户词典及输入方案 | 优先复用现有配置与 API；不再建立重复词频库 |
| 明确“保留此表达” | 本项目 `CorrectionLexicon` / `KeptTermsV1` | 只在用户明确操作后保存，用于过滤纠错；不参与 Rime 候选排序 |
| 自动纠错上下文 | 本项目跟踪的相邻上屏范围 | 有界、临时，不持久化全文，不自动添加保留词 |

高频不等于正确：重复的错别字不得仅因词频高而变成纠错白名单。未来若引入词频信号，必须先评估误判与反馈机制。测试学习仅使用独立词库；回退时清理该词库，不删除日常 Rime 或搜狗数据。

本轮根据用户指示在 `main` 继续开发，优先基本纠错、用户习惯和高频词；皮肤/位置自定义后置。新增操作已用于独立的手动检查窗口，尚未接入日常输入法的自动提示。

## 本轮可用功能

启动 `output\WeaselDeployer.exe /correction`，配置并启动模型后，手动检查本页文本。

1. 建议列表可选择疑似片段，查看原文、替换、原因与未校准的模型分数。
2. **应用到本页**：只修改当前窗口内的输入文字；按下按钮时再次检查版本、完整文本和原文位置。应用后旧建议全部失效，焦点回到本页文本框，可用 Ctrl+Z 撤销，再重新检查。不修改记事本等其他应用。
3. **忽略一次**：只移除当前这条建议，不保存规则，也不把忽略等同于“原文正确”。
4. **保留此表达**：用户明确声明原表达需要保留，将其立即保存到本地保留词，后续与该表达任一出现位置重叠的建议会被隐藏。按钮失败会保留原状态并显示原因。
5. **管理保留词**：可手动新增、删除选中项、清空；点击该子窗口的保存才写入变动，取消则丢弃子窗口内的编辑。主窗口的“恢复默认”只恢复模型设置，不删除保留词；主窗口取消也不会撤销已经明确保存的保留词。

保留词最多 256 条，每条最多 64 个 UTF-16 单元，去重，拒绝空表达、首尾空白、控制字符及破损 Unicode。它与 Rime 输入词典是不同的数据：保留词用于抑制纠错建议，不提高候选词排序，也不修改模型权重。

存储位置：当前用户 `HKCU\Software\Rime\Weasel\Correction` 中的 `KeptTermsV1`，单个带版本号的二进制 JSON 值。只保存用户明确保留的表达，不保存原文段落、上下文、模型密钥或分数。词表不放入 HTTP 请求，不发送给模型。读取失败时停止手动检查，避免静默丢失保护；可在管理窗口明确清空并保存恢复。

离线演示 `/correction-demo` 中的保留与管理仅在该次演示内生效，不写入注册表。所有自动化 GUI 测试使用内存词表，不修改真实用户的保留词。

## 高频词与输入习惯

本项目所带 Rime 已有持久化用户词典，无需额外记录全文来统计词频。源码依据：

- `RimeWithWeasel/RimeWithWeasel.cpp::_Setup` 设置独立的 Rime `user_data_dir`。
- `librime/src/rime/gear/memory.cc` 在提交事件上管理学习事务。
- `script_translator.cc::Memorize` 与 `table_translator.cc::Memorize` 调用用户词典 `UpdateEntry(..., 1)`。
- 用户词典查询参与候选生成和排序；能否学习仍取决于具体输入方案的配置、候选类型等。

本轮新增 `/rime-learning-selftest`，在自己的进程和全新微型词库中分别验证 `table_translator` 与 `script_translator`：

1. 同一个测试编码最初按静态词频把“默认词”排在第一，“习惯词”排在后面。
2. 通过真实 Rime 按键/选词 API，明确选择并提交“习惯词”5次。
3. 结束并重新初始化 Rime，重新从磁盘加载测试用户词库。
4. 确认“习惯词”排在第一；导出用户词典，确认提交次数准确为5。

两个架构、两种 translator 均通过。该测试使用 `output/RimeLearningTests/<架构>/<进程号>/` 下的共享配置和用户目录，不连接日常 WeaselServer、不启用系统输入法，也不访问真实 Rime 用户词库。它证明本项目引擎的基础机制，不能替代真实用户输入方案和应用的验收。本轮未修改 Rime 的算法或用户已有学习设置。

暂未将“高频词”自动视为纠错真值。经常输入的表达也可能是错误；明确的保留词与模型建议先分别处理，后续有标注数据后再设计词频抑制与排序。
