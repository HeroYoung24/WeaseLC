# 界面、模型管理与卸载边界调整（2026-11-10）

## 已实现的变更

- 候选词横排：确认底层已支持 style/horizontal，也有 style/layout/type 替代配置。按用户后续要求，不新增开关、不改候选词布局。
- 安装完成页默认勾选打开初始方案/配色设置；通过现有桌面 Explorer 的 COM 接口交接给桌面用户，不以管理员令牌回退启动。交接失败时提示从开始菜单打开。
- 安装器保留目录选择。支持 Program Files 以外的独立本地目录；目录长度受现有组件限制（最多160字符），拒绝盘符根目录、受保护目录、用户资料区、重解析路径、别名和穿越形式。
- 图标菜单增加模型管理、纠错快速开关；显示开关勾选状态。开始菜单增加模型管理和管理纠错快捷方式。
- 模型目录与 PowerShell 路径保存到独立产品配置。管理纠错新增“填入本地参数”，填写冻结4B的接口和模型名；仍由用户保存，不自动发送文本或启动模型。
- “应用与数据”改名“管理暂停纠错”。其已有暂停名单和行为记录功能保留。
- 最短展示/最长有效时间用秒输入，接受最多三位小数；采用精确十进制到整数毫秒的转换，内部存储格式和时钟逻辑保持不变。保留已有1–10秒、5–60秒范围。
- 运行中的模型窗口关闭后隐藏并继续后台运行；模型管理入口唤回同一窗口。新增“停止并退出”，现有停止操作仍可用。状态区区分自己管理的进程、就绪状态、未运行和外部已有服务；不接管外部进程。

## 卸载的安全边界

1. 卸载页不提供目录编辑、不展示删除目录，不采信命令行传入的替代路径；隐藏卸载明细中的路径。
2. 对照卸载器原始位置、受保护的 InstallLocation（旧beta仅回退到已有 WeaselRoot）、两种注册视图的根目录、实际组件目录、CLSID模块路径、必要组件及产品清单。
3. 目录被移动/复制、系统重装后记录丢失、注册异常、文件不完整、根或子目录存在链接等情形，删除前拒绝卸载。提示移回原位置或从同版本包恢复缺失组件；系统已无注册时，建议备份后手动删除明确属于产品的目录，不自动搜索或迁移记录。
4. 只删除构建时固定的文件清单和确切快捷方式，不递归清空目录。未知文件保留；仅为空时才移除已知目录。
5. 默认保留个人偏好；取消时仅清除本账户 Software\\WeaseLC 中的纠错设置、暂停名单和模型位置等记录。Rime输入方案/配色文件、用户词典、模型权重始终保留；其他用户资料不处理。
6. 卸载前尝试停止本产品自己启动的模型与后端，然后用 Restart Manager 枚举输入组件、运行库及后台程序占用者，显示应用名和PID及保存/关闭/重启资源管理器的指引。
7. 不强退其他宿主，不调用 RmShutdown。用户可取消并释放后重试，或确认继续、让仍占用的清单文件在重启后删除。NSIS自身使用临时副本机制。目录的延迟移除不递归，未知文件仍会阻止目录删除。
8. 注销错误依旧要求双架构检查实际注册/类别已无残留，不能把通用 E_FAIL 一律视为成功。

## 本轮验证及后续验收

- 双架构编译、离线界面、三位小数往返/非法值拒绝和目录保护自检。最终结果以候选包 package-check.json 为准。
- 目录用例包括本机非 Program Files 的自定义位置、盘符根、Windows、原生及x86 Program Files根、含 .. 的路径和 ProgramData。
- 本轮未重新安装、不注册测试输入法、不启动真实模型，继续保留用户暂停实机纠错验收的要求。
- 待实机/虚拟机：默认与E盘自定义目录安装；完成页以普通用户弹出设置；快速开关与后台模型重开/显式停止；模型位置重开记忆；两种个人偏好选项；占用提示/释放/延迟删除；移动整个目录、只复制卸载器、清除安装记录后拒绝卸载；内部链接和未知文件保留。
- 系统重装/移动、重解析点和故意破坏注册的用例应在隔离环境以合成文件与注册测试，不在日常系统上模拟破坏原生输入法。
