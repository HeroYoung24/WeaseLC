# 增强输入流程：控制器适配及实机测试准备

2026-11-03：已完成实际TSF、配置、窗口和协调器适配，最终双架构构建/完整回归通过。可以准备独立实机包；本文件中的“通过”指自动或隔离宿主结果，尚不等于Edge人工验收。

## 实际接入

- 新增AutomaticCorrectionFlow.inc，在原控制器中接入5项队列、64项有界终态标记、单次Tab/Esc、年龄/可见时间及一个在途/一个最新快照调度；原尾部/拼音写回和写后确认仍是唯一修改通道。
- 原默认提示时机保留：下次输入模式的第一条等待拼音；显示后可在短词上屏时继续保留，队列接续待当前按键释放。立即模式也可用。
- 默认最短可见3000ms、最长有效15000ms；排队计入最长年龄，隐藏不计最短时间。过期及来源变化优先，临到期不足展示时间不会闪现。
- 每个完整Tab键周期最多一次尝试。明确Esc拒绝不立即复现，下一项等Esc释放和新的普通输入机会；组合内Esc只取消拼音。
- 等价句号/逗号视图合并、旧词法快照结果丢弃，最新检查有有限调度机会。等价尾部扩展仍逐项核对新原文；不凭旧坐标猜测替换。
- 改字后在新的同步宿主会话中重建来源/选区/拼音并逐项核对下一条，支持长度变化。写回期间屏蔽队列推进/到期和重入定时器；未确认写入不重放、不推进。
- 提示绘制/辅助文本增加“另有N处”，只表示当前队列，不表示全文错误总数。

## 设置与兼容

“管理纠错→自动提示”新增实验增强开关、最短/最长毫秒字段及短词3秒/长段5秒参考按钮；允许自选，最短不得大于最长。三种语言均有控件，输入顺序和界面截图已检查。

配置v5支持读取v2/v3/v4，旧配置默认不启用增强；现有模式/模型/主题等保留。私有协调器协议升至v4并严格拒绝不匹配版本，需要成套更新六文件，不能只换DLL。

增强流程暂不发送旧单建议行为学习票据，界面已明确“不记录纠错行为”；旧流程行为学习能力保留。实测前继续核对用户关闭的学习开关，不自动开启。Rime词频学习/词库不受此开关影响。Word仍仅普通输入。

## 尚需实机及保留边界

1. 新包先Off普通输入，再Fixed单项/两项、短词确认、长按Tab、Esc和时长，再真实冻结4B；每阶段核对实际加载哈希。
2. 新增固定测试语料“这里有错子，也在图书管。”，只编入独立测试产品，仍经过原解析/保护，不能用于正式模式硬编码纠错。
3. 第一次部署前默认不自动开启增强；人工阶段才用设置或Set-LocalTestPhase.ps1 -AdvancedFlow显式启用。
4. 多屏、辅助技术、更多应用、真正大段分片、长期性能和质量集仍待。单个不可安全捕获的超长提交不强制确认或全文读取；来源仍限1024单元。64项处理标记/记录满后本scope停止新准入，不循环刷新身份来规避拒绝标记。
5. 本轮没有参数重调或新模型下载。没有通用原回答缓存；在途合并和已核对等价标点复用不意味着所有跨文本结果都可缓存。
